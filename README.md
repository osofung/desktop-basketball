# Physics-Based Desktop Basketball Game

A 2D physics simulation game developed in Godot, featuring realistic physics and a unique window-transparency mode designed for seamless multitasking.

## Overview

This project was built to explore game physics and custom window management. The game features a 2D physics simulation and a "click-through" feature, allowing the game window to remain active in the background while the user continues to work or multitask.

## Key Features

- Realistic 2D physics using Godot's Physics2D engine to simulate basketball movement and collisions
- Desktop transparency for low-profile operation while the game sits on the desktop
- Click-through functionality using custom polygonal regions, allowing interaction with windows behind the game
- Lightweight design intended to minimize system impact during multitasking

## Tech Stack

- Godot
- GDScript
- Physics2D

## Project Goals

- Explore advanced window manipulation techniques in a game environment
- Create a desktop "fidget toy" experience that balances gameplay with utility
- Strengthen game development skills through custom physics-based interaction design

## Current Status

This project is still in development. The core physics and click-through mechanics are functional, but the game is still being refined and expanded.

## Why I Built This

I wanted to create a small game that could also function as a desktop utility rather than just a standalone distraction. This project was also a way to experiment with physics simulation, window behavior, and interaction design in Godot.

## Known Limitations

- Currently focused more on core mechanics than content depth
- May be optimized for specific desktop environments only
- Some gameplay systems and polish are still incomplete
